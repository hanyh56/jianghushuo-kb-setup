# 默认目录名称与旧库保护

新建知识库使用以下六个编号加中文的名称，系统目录仍为 `90-系统/`。保留各库原来的职责和内部分类。

| 旧安装模板 / 旧个人目录 | 新名称 |
| --- | --- |
| `00-灵感与收件箱` / `00-Inbox(灵感库)` | `00-灵感库` |
| `01-Projects-当前任务` / `01-Projects(项目)` | `01-项目库` |
| `02-Areas-长期领域` / `02-Areas(资产)` | `02-资产库` |
| `03-Resources-参考资料` / `03-Resources(资源)` | `03-资源库` |
| `04-Archive-归档` / `04-Archive(归档)` | `04-归档库` |
| `05-Skills-经验复利` / `05-Skills(技能)` | `05-技能库` |

发现旧目录时，安装器在写入前停止，避免同时创建两套内容目录。先读取该库的协作规则和迁移映射。用户只更新安装 Skill 时，备份更新 Skill 文件并保留实际库结构，日常入口沿用实际路径；不要为通过新建库验收而迁移笔记。

用户明确要求目录改名时，先备份并核对目标名称冲突，再移动六个主目录，保留内部分类、文件名、事实与状态；同步库内链接、看板、收件箱、日记和工作区路径。导出 ZIP 内原件不改。历史迁移键、哈希与旧更名记录保留，新的目录更名映射按时间追加，旧路径按迁移链解析。写后回读并核对移动前后文件及配置，不因改名创建假项目或重新访谈。

安装包内部目录更新后，实际安装与包复制以 `assets/vault-manifest.json` 为准；旧版安装 Skill 遗留的包内目录不再次复制进用户知识库。
