# 个人知识库

知识库绝对路径（JSON 字符串，按 JSON 解析；不要当 shell 命令执行）：

{{VAULT_PATH_JSON}}

先读取该目录的 `AGENTS.md`、`知识资产工作台.md` 和 `90-系统/维护与AI协作规则.md`，再按真实问题局部检索。目录不可读时检查当前会话的文件访问范围，不虚构检索结果，不在别处创建替代空库。

涉及个人协作时，按维护规则读取个人说明入口及当前任务必要的背景。发现“待开始访谈”或“访谈中”时，先读 `90-系统/我是谁访谈规则.md`，在可交互的本轮接续一个问题并等待；已暂停/跳过的等用户继续，初版可用的直接复用，不因重装或更新重新盘问。个人说明或入口尚不存在时按规则先查已有档案，不编造用户背景。保存与当前工具读取不代表所有 AI 自动获得长期记忆。

- 灵感进 `00-灵感库/`；有具体结果的任务进 `01-项目库/`。
- 长期经历和判断进 `02-资产库/`；本人原文和外部资料分开放在 `03-资源库/`。
- 历史或暂停材料进 `04-归档库/`；方法进 `05-技能库/`，未经使用的留在待验证方法。
- 用户要求记录或维护时先查重、实际写入、回读并核对链接。普通讨论不自动保存。
- 原话、本人确认观点、外部观点、推测和 AI 建议分开；不编经历，不把计划或测试数据写成成果。
- 使用库内模板时替换真实标题和本地日期；不知道的事实留空。材料默认私密。

只回答“知识库在哪”时给出实际路径和入口；不要因此重新运行安装或扫描全库。
