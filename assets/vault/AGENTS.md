# 知识库协作入口

先读 `知识资产工作台.md` 和 `90-系统/维护与AI协作规则.md`。按当前问题只读相关索引与必要原文。

- 灵感：`00-灵感与收件箱/`；当前任务：`01-Projects-当前任务/`。
- 长期经历与责任：`02-Areas-长期领域/`；来源与外部参考分开放在 `03-Resources-参考资料/`。
- 历史或暂停材料：`04-Archive-归档/`；可复用方法：`05-Skills-经验复利/`。
- 本人事实、原话、已确认观点、推测和 AI 建议分别标明。不编经历，不把计划写成成果。
- 保留原文、来源、日期和已有编号；先查重再增补，写后回读并核对相关链接。
- 已有专用规则先读再遵守；旧路径有迁移映射时先查映射，不重建旧目录。
- 家庭、关系、健康、收入和公司材料默认私密；整理和可检索不等于公开授权。
- 只操作本次任务需要的材料。安装结构不代表自动同步、跨会话加载或定时执行已经建立。
