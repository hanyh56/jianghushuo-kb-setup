# 从眼前的问题开始

先打开 [[知识资产工作台]]。安装成功后，Agent 会简短介绍下面这些目录，再接上“我是谁访谈”。不用先补齐资料，不要求每天清空收件箱。

## 每个文件夹做什么

下面是默认安装创建的目录；已有知识库按实际名称和迁移映射使用。

| 文件夹 | 作用 |
| --- | --- |
| `00-灵感与收件箱/` | 先接住零散想法和暂未分类的记录，有需要再整理。 |
| `01-Projects-当前任务/` | 推进有具体结果和结束标准的任务，按实际任务建立项目。 |
| `01-Projects-当前任务/待确认是否继续/` | 保留缺少最新进展证据的任务，确认继续后再恢复推进。 |
| `02-Areas-长期领域/` | 保存长期角色、责任、经历和判断，以及“我是谁”个人说明。 |
| `02-Areas-长期领域/每日记录/` | 按日期记录真实动作与反馈，不要求每天填写。 |
| `03-Resources-参考资料/` | 保存做事时需要查阅的材料，本人记录与外部参考分开。 |
| `03-Resources-参考资料/本人原始记录/` | 保存本人的笔记、聊天等原始资料，保留原话和来源。 |
| `03-Resources-参考资料/本人原始记录/来源导入/` | 承接导出的来源材料，保留时间和定位信息，重复导入先查重。 |
| `03-Resources-参考资料/外部参考/` | 保存他人文章、书摘等参考，标明来源，不当成本人经历。 |
| `04-Archive-归档/` | 保存结束、暂停或暂时不用的材料；归档不代表已经完成。 |
| `05-Skills-经验复利/` | 沉淀下次可复用的流程、清单和方法，注明实际证据与适用边界。 |
| `05-Skills-经验复利/待验证方法/` | 暂存尚未实际试用的办法或 AI 建议，使用后补结果。 |
| `90-系统/` | 保存协作规则、接入说明、访谈规则、模板和看板配置。 |
| `90-系统/模板/` | 保存五类笔记的空白格式，新建记录时按需套用。 |
| `.obsidian/` | Obsidian 的库内设置目录；不用于存放笔记，部分界面默认隐藏。 |

`05-Skills-经验复利/` 中的方法笔记不会自动成为可执行的 Agent Skill；安装 Skill 和 `personal-kb` 位于宿主实际读取的技能目录。

## 从手里的材料开始

平时只做三件事：随手记；做事时找对应项目；下次使用时补实际结果。

这是受姜胡说知识管理思路启发、保留 PARA 长期领域的适配结构。来源与边界见 [[90-系统/方案说明]]。默认在 Obsidian 查看，Agent 也能直接读写通用 Markdown；[[第一次使用]] 提供自然语言入口。
