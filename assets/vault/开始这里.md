# 从眼前的问题开始

先打开 [[知识资产工作台]]。不用先补齐资料，不要求每天清空收件箱。

| 手里有什么 | 放哪里 |
| --- | --- |
| 一闪而过的想法 | `00-灵感与收件箱/` |
| 有具体结果的任务 | `01-Projects-当前任务/项目名/` |
| 长期承担的责任、经历和判断 | `02-Areas-长期领域/` |
| 本人原文、对话来源、外部资料 | `03-Resources-参考资料/`，本人记录与外部观点分开 |
| 暂停、结束或暂时不用的材料 | `04-Archive-归档/`，归档不等于完成 |
| 下次可以调用的流程和清单 | `05-Skills-经验复利/`，未经实际验证的先放待验证方法 |

平时只做三件事：随手记；做事时找对应项目；下次使用时补实际结果。

这是受姜胡说知识管理思路启发、保留 PARA 长期领域的适配结构。来源与边界见 [[90-系统/方案说明]]。通用 Markdown 可直接由 Agent 读写；Obsidian 可作为可选界面。
