# 第一次使用

你不需要先整理旧资料。直接对 Agent 说：

- “把这个想法记入我的知识库：……”
- “我要做这件事，帮我建一张项目卡：……”
- “找一下我以前关于……的记录。”

Agent 会按实际内容创建笔记、查重和回读。想亲自查看，就打开 [[知识资产工作台]]。

在 Obsidian 中，新笔记默认放入收件箱。插入模板时，从命令面板选择“插入模板”；每日记录使用内置日记功能。模板提供记录结构，空字段不用补造事实。

换一个 Agent 会话时，说“我的知识库在哪”。本机已配置的 `personal-kb` skill 或宿主指令会提供路径；若宿主尚未刷新 skills，刷新或重新开启会话。其他设备需要独立安装和文件访问权限，本次安装不建立云同步。

没有现实任务时，不必创建演示项目。目录、模板和规则已经可用；下次有真实问题再开始。
