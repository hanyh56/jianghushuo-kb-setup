# 第一次使用

知识库安装并通过实际读写验收后，Agent 会先简短说明各目录的用途（完整说明见 [[开始这里]]），随后在同一条回复中开始“我是谁访谈”，一次只问一个问题，帮你整理以后协作时可参考的个人说明。你可以提供现成记录，也可以从最近正在做的事说起，随时暂停或跳过；不用先整理旧资料。已有说明会先读取复用，未完成的从进度接续，完成的不会因重装再问一遍。

没有可交互对话时，Agent 会保存“待开始访谈”，在下次可交互使用知识库时接续，不会在后台自行发消息。说明只记录你明确提供的信息，写入后回读；实际位置会记在个人说明入口。详见 [[90-系统/我是谁访谈规则]]。

日常可以直接对 Agent 说：

- “把这个想法记入我的知识库：……”
- “我要做这件事，帮我建一张项目卡：……”
- “找一下我以前关于……的记录。”

Agent 会按实际内容创建笔记、查重和回读。想亲自查看，就打开 [[知识资产工作台]]。

在 Obsidian 中，新笔记默认放入收件箱。插入模板时，从命令面板选择“插入模板”；每日记录使用内置日记功能。模板提供记录结构，空字段不用补造事实。

换一个 Agent 会话时，说“我的知识库在哪”。本机已配置的 `personal-kb` skill 或宿主指令会提供路径；若宿主尚未刷新 skills，刷新或重新开启会话。其他设备需要独立安装和文件访问权限，本次安装不建立云同步。

没有现实任务时，不必创建演示项目。个人说明先形成够用的初版，其他资料以后按真实需要补充。
