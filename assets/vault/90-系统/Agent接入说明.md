# 接到你的 Agent

把本库的真实绝对路径写入该 Agent 实际支持的项目指令或记忆入口，内容如下：

> 个人知识库位于这里提供的绝对路径。涉及我的经历、项目或可复用方法时，先读取库根目录的 AGENTS.md、知识资产工作台.md 和 90-系统/维护与AI协作规则.md，再按问题局部检索。普通讨论不自动入库；用户要求记录时按规则写入并回读。默认私密，计划与成果分别标明。

安装器的 `--skills-dir` 会在当前宿主的技能目录生成 `personal-kb/SKILL.md`，其中保存本库真实路径。也可用 `--agent codex` 或 `--agent claude` 使用对应的标准个人技能目录。日后可直接说“我的知识库在哪”“找以前的记录”“把这个记入知识库”。

只有指令文件机制时，`--agent-file` 会追加包含实际路径的入口块。宿主没有持久机制时，当前会话先读规则，并保留持久接入待办。当前会话的读取结果和跨会话加载情况分别验证。

用文件工具或运行 `scripts/install.py --vault "实际路径" --skills-dir "宿主实际技能目录" --check` 检查结构、配置和入口；再让 Agent 实际读入口。未配置外部入口时，知识库根目录的 AGENTS.md 只对读取它的 Agent 生效。文件权限按宿主实际支持的流程设置。
