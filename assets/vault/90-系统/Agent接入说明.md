# 接到你的 Agent

把本库的真实绝对路径写入该 Agent 实际支持的项目指令或记忆入口，内容如下：

> 个人知识库位于这里提供的绝对路径。涉及我的经历、项目或可复用方法时，先读取库根目录的 AGENTS.md、知识资产工作台.md 和 90-系统/维护与AI协作规则.md，再按问题局部检索。普通讨论不自动入库；用户要求记录时按规则写入并回读。默认私密，计划与成果分别标明。

安装器的 `--agent-file` 会生成包含实际路径的入口块。宿主不支持指令文件时，在当前会话提供路径并要求先读规则。当前会话的读取结果和跨会话加载情况分别验证。

在具备本地终端权限的 Agent 中，用文件工具或运行 `scripts/install.py --vault "实际路径" --check` 检查结构；再让 Agent 实际读入口。未指定外部入口时，知识库根目录的 AGENTS.md 只对读取它的 Agent 生效。
