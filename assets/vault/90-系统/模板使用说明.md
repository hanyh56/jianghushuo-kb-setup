# 模板使用说明

在对应目录新建 Markdown，复制需要的模板。把 `{{title}}`、`{{date:YYYY-MM-DD}}` 替换为真实标题和本地日期；不用的字段可以留空或删掉，不编造事实来填表。

| 要记什么 | 模板 |
| --- | --- |
| 灵感 | [[90-系统/模板/模板-灵感]] |
| 当前任务 | [[90-系统/模板/模板-项目推进]] |
| 长期理解或判断 | [[90-系统/模板/模板-知识卡]] |
| 可复用方法 | [[90-系统/模板/模板-经验工作流]] |
| 当天真实动作和结果 | [[90-系统/模板/模板-每日进度]] |

安装器已配置内置模板、日记和 Bases：模板目录为 `90-系统/模板/`，日记目录为 `02-Areas-长期领域/每日记录/`，新笔记默认进入收件箱，移动文件会自动更新链接。只更新这些相关设置，保留其他设置；已有配置改动前会生成同目录备份。打开中的旧库需要重新加载后生效。

其他 Agent 直接复制模板并替换占位符即可。[[第一次使用]] 提供自然语言入口。
