# 方案说明

此包提炼自 2026-10-25 已在本地整理的知识库适配结构，作为通用空白起点。它受姜胡说“当前任务、经验复利、参考资源、搁置区”思路启发，同时保留 PARA 的长期领域，再加收件箱承接未定想法。

这是适配方案，不是姜胡说官方发布的唯一目录或完整课程。此前的归因依据限于可检索的平台文字；本包没有新增对原视频的逐字核实，也没有分发付费材料。

六个内容目录服务于不同用途，`90-系统/` 存模板、规则和可选视图。不预设用户经历、职业或已有能力，不包含制作本包者的私人资料、原库导出、绝对路径、账户或自动化设置。

Markdown 和本地文件是核心。默认完整落地流程会检测并安装 Obsidian，配置模板、日记、收件箱和内置 Bases，随后注册并打开知识库。只使用 Agent 或运行于无桌面环境时，可交付文件层并明确说明桌面步骤的状态。不安装第三方插件，不要求购买同步服务或注册账号。
